# 设计构想（Conception）

主要由用户完成（可能与 AI 头脑风暴），主要是探索思考、分析问题，澄清目标，以及为什么。主要是 **What** 和 **Why** 的逻辑。

不过如果必要，也可以包含具体的想法和细节，或者某些技术选择。

**维护规则：**

- 当用户或用户委托 Agent 完成一份构想文档时，更新上面的清单。
- 文件命名约定：
  - `0.` / `1.` / … — 按主题顺序编号的核心设计文档；
  - `Base-` — 框架级总览与架构指引；
  - `Ploy-` — 针对特定机制的策略/方案文档。
- 新增 Conception 前，先检查 [0.设计.md](0.设计.md) 是否已涵盖该主题；若已涵盖，优先在原文档中扩展或交叉引用，避免重复。
- Decision 层不得覆盖 Conception 已明确的规则；若 Conception 修订吸收了某条 Decision，应同步标注或删除对应 Decision。
